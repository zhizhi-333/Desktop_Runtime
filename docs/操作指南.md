## 1. 装置简介

这是一个基于 STM32F407ZG 微控制器的嵌入式智能终端，运行 FreeRTOS 实时操作系统，具有以下特点：

- **屏幕**：3.5 英寸 TFT LCD，480×320 分辨率，横屏显示
- **输入**：4×4 矩阵键盘 + 旋转编码器（含按压开关）
- **存储**：SD 卡（文件系统）+ Flash（系统设置）+ RTC 后备电池（时间保持）
- **音频**：DAC 输出方波音乐
- **通信**：USART3 串口（115200 波特率，用于日志输出）
- **可靠性**：独立看门狗（IWDG）、任务心跳检测、CRC 数据校验

装置上电后会经历：开机画面 → 登录界面（需输入密码）→ 桌面 → 选择应用操作。

## 2. 硬件配置一览

### 2.1 已启用的硬件模块

| 模块 | 用途 | 对应代码位置 |
|------|------|-------------|
| GPIO | LED、按键、LCD 控制脚 | `gpio.c` |
| SPI1 | 驱动 LCD 屏幕 | `spi.c` |
| USART3 | 串口日志输出（PD8/PD9，115200） | `usart.c` |
| TIM4 | 编码器计数（PB6/PB7） | `tim.c` |
| TIM6 | DAC 触发定时器（音频） | `dac.c` |
| DAC1 | 音频输出（PA4） | `dac.c` |
| SDIO | SD 卡读写（4 位总线） | `file_sys.c` |
| RTC | 实时时钟（LSE 32.768kHz） | `rtc_time.c` |
| IWDG | 独立看门狗（超时 12.5 秒） | `monitor.c` |
| FLASH | 存储系统设置（Sector 11） | `settings.c` |

对应配置文件：`Core/Inc/stm32f4xx_hal_conf.h`，需要使用的模块其 `#define HAL_xxx_MODULE_ENABLED` 必须未被注释。

### 2.2 引脚分配

| 外设 | 引脚 | 说明 |
|------|------|------|
| LED0 | PF9 | 板载指示灯，500ms 闪烁表示系统正常运行 |
| 矩阵键盘行 0~3 | PE0~PE3 | 4 行扫描输出 |
| 矩阵键盘列 0~3 | PE4/PE5/PE7/PE8 | 4 列读取输入 |
| 输入器检测 | PE6 | 检测键盘是否连接（高=已连接） |
| 编码器 A 相 | PB6 | TIM4_CH1 |
| 编码器 B 相 | PB7 | TIM4_CH2 |
| 编码器开关 | PB8 | 按压检测 |
| LCD CS | PB12 | 片选 |
| LCD DC | PB13 | 数据/命令选择 |
| LCD RST | PB14 | 复位 |
| LCD 背光 | PB15 | 高电平=亮 |
| LCD SPI SCK | PA5 | SPI1 时钟 |
| LCD SPI MOSI | PA7 | SPI1 数据输出 |
| 串口 TX | PD8 | USART3 发送 |
| 串口 RX | PD9 | USART3 接收 |
| DAC 音频输出 | PA4 | DAC1_CH1 |
| SD 卡 D0~D3 | PC8~PC11 | SDIO 4 位数据 |
| SD 卡 CLK | PC12 | SDIO 时钟 |
| SD 卡 CMD | PD2 | SDIO 命令 |

### 2.3 FreeRTOS 配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| CPU 主频 | 168 MHz | HSE 8MHz 倍频 |
| Tick 频率 | 1000 Hz | 1ms 一次中断 |
| 总堆大小 | 48 KB | 所有任务/队列/互斥量共享 |
| 最大优先级 | 7（0~6） | 数值越大优先级越高 |
| 栈溢出检测 | 级别 2 | 全面检查，溢出触发钩子 |

### 2.4 任务列表

| 任务名 | 优先级 | 栈大小 | 周期 | 职责 |
|--------|--------|--------|------|------|
| InputTask | 3（最高） | 2KB | 20ms | 扫描按键、管理 UI、分发事件 |
| LedTask | 2 | 1KB | 500ms | LED 闪烁，肉眼确认调度器运行 |
| FileTask | 2 | 4KB | 等待队列 | 后台文件 I/O（避免阻塞 UI） |
| MusicTask | 2 | 2KB | 20ms | 后台音乐播放推进 |
| MonitorTask | 1（最低） | 4KB | 1000ms | 系统健康监控、看门狗喂狗、负载分析 |

对应代码：`User/app/monitor.c`（Monitor/Led/Input）、`User/app/file_task.c`（File）、`User/app/music_task.c`（Music）。

## 3. 按键说明

### 3.1 矩阵键盘布局

```
         列0     列1     列2     列3
         (PE4)   (PE5)   (PE7)   (PE8)
行0(PE0)  ↑                       ←
行1(PE1)          OK
行2(PE2)                  BACK
行3(PE3)  ↓                       →
```

共 6 个功能键：**↑（上）、↓（下）、←（左）、→（右）、OK（确认）、BACK（返回）**。

### 3.2 旋转编码器

| 操作 | 说明 |
|------|------|
| 顺时针旋转 | 通常=增大/下一项 |
| 逆时针旋转 | 通常=减小/上一项 |
| 按压编码器（按下开关） | 应用内=最小化应用；桌面=锁屏 |

### 3.3 按键去抖

所有按键经过软件去抖（连续 3 次采样一致才生效），采样周期 20ms，因此按键响应延迟最多约 60ms。

对应代码：`User/dev/key.c` 的 `Key_Scan()` 函数。

## 4. 开机流程

上电后系统按以下顺序启动（全程约 3~5 秒）：

1. **硬件初始化**（约 0.5 秒）：时钟、GPIO、SPI、LCD、串口等
2. **开机画面**（2 秒）：显示标题、加载信息、进度条、版本号
3. **FreeRTOS 调度器启动**：5 个任务开始运行
4. **RTC 初始化**（InputTask 中）：检测 LSE 晶振、读取时间
5. **SD 卡初始化**（InputTask 中，通过 FileTask 异步）：加载文件表
6. **登录界面**：等待用户输入密码

串口会输出详细启动日志，可接 USB-TTL 模块在电脑上查看（115200, 8N1）。

对应代码：`Core/Src/main.c` 的 `main()` 函数。

```
┌──────────────────────────────────┐
│ LOGIN       [*][*][ ][ ]         │
│        [ERROR / PASS OK]         │
│  ┌─┐┌─┐┌─┐┌─┐┌─┐                 │

│       └─┘└─┘└─┘                  │

```

**密码是 `1234`**（4 位数字）。

操作方式：
- 用方向键移动光标到数字按钮上，按 **OK** 输入该数字
- 输入的数字会显示为 `*`（密码遮挡）

- **<** = 退格删除最后一个字符
- **OK** = 确认提交密码

密码正确：显示 "PASS OK"（绿色），1 秒后进入桌面。
密码错误：显示 "ERROR"（红色），可重新输入。
连续错误 3 次：锁定 30 秒，期间无法操作。

对应代码：`User/app/login.c`。

## 7. 应用详解

### 7.1 FILE 文件管理

**功能**：管理 SD 卡上的文件，支持新建、查看、编辑、删除、重命名。

**限制**：最多 16 个文件，每个文件最大 512 字节，文件名 8.3 格式。

#### 界面：文件列表

```
┌──────────────────────────────────┐
│ FILE MANAGER         [NO SD!]    │
│                                  │
│ > FILE01.TXT   128B  T          │  ← 黄色光标选中的文件
│   FILE02.BIN   256B  D          │
│   FILE03.CFG    32B  C          │
│                                  │
│ ←NEW  →DEL  OK:OPEN  BACK:EXIT  │  操作提示
└──────────────────────────────────┘
```

**文件类型标识**：`T`=文本，`D`=绘图，`C`=配置

#### 操作

| 按键 | 效果 |
|------|------|
| ↑/↓ | 选择上一个/下一个文件 |
| OK | 打开选中文件查看内容 |
| ← | 新建文件（弹出字符网格输入文件名） |
| → | 删除选中文件（弹出确认） |
| BACK | 退出文件管理，回桌面 |

#### 界面：查看文件

```
┌──────────────────────────────────┐
│ VIEW: FILE01.TXT                 │
│ ┌──────────────────────────────┐ │
│ │ Hello World!                 │ │  文件内容
│ │ This is a test file.         │ │
│ │                              │ │
│ └──────────────────────────────┘ │
│ OK:EDIT  BACK:LIST               │
└──────────────────────────────────┘
```

| 按键 | 效果 |
|------|------|
| ↑/↓ | 滚动查看内容 |
| OK | 进入编辑模式 |
| BACK | 返回文件列表 |

#### 界面：编辑文件（字符网格）

```
┌──────────────────────────────────┐
│ EDIT: FILE01.TXT                 │
│ Preview: Hello World!_           │  当前输入预览
│ ┌──┐┌──┐┌──┐┌──┐┌──┐┌──┐...    │  字符网格
│ │ A││ B││ C││ D││ E││ F│         │  10列 x 4行
│ └──┘└──┘└──┘└──┘└──┘└──┘        │
│ ...                              │
│ [>] = SAVE                       │
└──────────────────────────────────┘
```

字符网格包含 A~Z、0~9、空格、退格(`<`)、保存(`>`)、点(`.`)。

| 按键 | 效果 |
|------|------|
| ↑↓←→ | 在字符网格中移动光标 |
| OK | 选中当前字符（输入到文件中） |
| BACK | 取消编辑，返回查看界面 |
| 选中 `>` | 保存文件 |

**无 SD 卡时**：标题显示 `[NO SD!]`，无法进行任何文件操作。

对应代码：`User/app/app_file.c`。

### 7.2 DRAW 画图

**功能**：在画布上绘制图形，支持 7 种颜色，保存到 SD 卡，掉电不丢失。

#### 界面

```
┌──────────────────────────────────┐
│ DRAW  DN  RED  X:240 Y:180  CLR │  状态栏
├──────────────────────────────────┤
│                                  │
│                                  │  画布区域
│           （在此画图）            │  480 x 292 像素
│                                  │
│                                  │
└──────────────────────────────────┘
```

**状态栏含义**：
- `DN` = 落笔状态（DN=落笔中画线，UP=抬笔只移动不画线）
- `RED` = 当前画笔颜色
- `X:240 Y:180` = 画笔当前坐标
- `CLR` = 提示编码器按压可清空

#### 操作

| 按键 | 效果 |
|------|------|
| 方向键 | 移动画笔（步长=设置中的光标灵敏度） |
| OK | 切换落笔/抬笔状态 |
| 编码器旋转 | 切换画笔颜色（7 色循环：白→红→绿→蓝→黄→青→品红） |
| 编码器按压 | 清空画布 |
| BACK | 退出（有操作时弹保存确认框，无操作直接退出） |

#### 保存确认

退出时如果本次有画图操作，会弹出确认框：

```
┌──────────────┐
│ Save drawing?│
│  [YES] [NO]  │
└──────────────┘
```

- 选 **YES**：保存到 SD 卡（文件名 DRAW.BIN），下次进入可恢复
- 选 **NO**：不保存，退出到桌面

**注意**：如果进去后什么都没画就退出，不会弹出保存确认框。

对应代码：`User/app/app_draw.c`。

### 7.3 MUSIC 音乐播放

**功能**：播放预置旋律，支持播放/暂停/停止、切歌、音量调节。

#### 界面

```
┌──────────────────────────────────┐
│ MUSIC PLAYER                     │
│ Tracks:                          │
│ > 1. Two Tigers                  │  ← 选中曲目
│   2. Little Star                 │
│   3. Happy B-Day                 │
├──────────────────────────────────┤
│ Now: Two Tigers                  │  当前播放
│ Note: C4   [####------] 4/34     │  音符 + 进度条
│ State: PLAYING  Vol: 50%  ISR:123│  状态 + 音量 + 诊断
├──────────────────────────────────┤
│ OK短:Play/Pause OK长:Stop EC:Vol │  操作提示
│ EC_SW:Minimize  BACK:Exit        │
└──────────────────────────────────┘
```

#### 操作

| 按键 | 状态 | 效果 |
|------|------|------|
| ↑/↓ | 未播放 | 选择上一首/下一首曲目 |
| ↑/↓ | 播放中 | 直接切换到上一首/下一首并立即播放 |
| OK 短按（<1秒） | 任意 | 播放/暂停切换 |
| OK 长按（≥1秒） | 任意 | 停止播放（回到 IDLE） |
| 编码器旋转 | 任意 | 调节音量（0~100%） |
| 编码器按压 | 任意 | 最小化（音乐继续后台播放，回桌面） |
| BACK | 任意 | 退出并停止播放 |

#### 最小化后台播放

按压编码器后，音乐应用最小化到任务栏，但音乐**继续播放**。桌面任务栏会显示 `[1]MUSIC` 图标。点击该图标可切回音乐应用。

**音量说明**：音量调节会同步保存到系统设置，掉电后保持。

对应代码：`User/app/app_music.c` + `User/app/music_task.c`。

### 7.5 MONITOR 系统监控

**功能**：实时显示系统运行状态，包括任务栈水位、队列水位、内存使用等。支持两页切换。

#### Page 0：实时数据

```
┌──────────────────────────────────┐
│ SYSTEM MONITOR       [BACK] DesK │
│ ──────────────────────────────── │
│ Uptime:           00:05:30       │  运行时间
│ State:            APP            │  系统状态
│ FreeHeap:         31520 B        │  剩余堆内存
│ MinHeap:          30200 B        │  历史最小堆
│ MonStack:          954 W         │  MonitorTask 栈剩余
│ LedStack:          214 W         │  LedTask 栈剩余
│ InpStack:          180 W         │  InputTask 栈剩余
│ FileStack:         512 W         │  FileTask 栈剩余
│ MusicStack:        300 W         │  MusicTask 栈剩余
│ FileReqQ:            0           │  文件请求队列水位
│ FileRespQ:           0           │  文件响应队列水位
│ MusicCmdQ:           0           │  音乐命令队列水位
│ InpEvents:         142           │  输入事件总数
│ DrpEvents:           0           │  丢弃事件数
│ Errors:              0           │  错误计数
│ TaskState:       RRRRR           │  5 个任务运行状态
└──────────────────────────────────┘
```

**TaskState 字符含义**：
```
TaskState: RRRRR
           |||||
           ||||+-- MusicTask
           |||+--- FileTask
           ||+---- InputTask
           |+----- LedTask
           +------ MonitorTask
```
- `R` = Running（运行中）
- `r` = Ready（就绪）
- `B` = Blocked（阻塞等待）
- `S` = Suspended（挂起）
- `D` = Deleted（已删除）

#### Page 1：历史峰值

按 **OK** 切换到第二页，显示历史峰值数据：

```
┌──────────────────────────────────┐
│ SYS MONITOR [P2:Peak] [BACK] DesK│
│ ──────────────────────────────── │
│ MonMinStk:   950 W  (品红色)     │  Monitor 栈历史最小值
│ LedMinStk:   210 W               │  LED 栈历史最小值
│ InpMinStk:   175 W               │  Input 栈历史最小值
│ FileMinStk:  510 W               │  FileTask 栈历史最小值
│ MusicMinStk: 298 W               │  MusicTask 栈历史最小值
│ FileReqPeak:   2                 │  文件请求队列历史峰值
```

**MinStk 含义**：栈历史最小剩余值（=最大使用量）。数值越小表示栈用得越多，接近 0 说明快溢出了。

| 按键 | 效果 |
|------|------|
| OK | 切换 Page 0 / Page 1 |
| BACK | 退出，回桌面 |

## 10. 状态栏含义

桌面底部状态栏从左到右：

### 错误代码

| 显示 | 含义 | 可能原因 |
|------|------|----------|
| `ERR:OK`（绿色） | 无错误 | 正常运行 |
| `ERR:INP`（红色） | 输入设备断开 | 键盘排线松动或拔出 |

## 11. 串口日志说明

用 USB-TTL 模块连接 **PD8（TX）→ 电脑 RX**，**GND → GND**，波特率 **115200, 8N1**，即可看到系统日志。

### 常见日志

| 日志 | 含义 |
|------|------|
| `[BOOT] MCU init done, starting FreeRTOS...` | 硬件初始化完成，启动 RTOS |
| `[WDT] IWDG initialized (timeout ~12.5s)` | 看门狗已启动 |
| `[MON] tick=603 free_heap=31520 ...` | 每秒一次系统状态 |
| `[INPUT] RTC init...` | 开始初始化 RTC |

| `[FS] table CRC not present (first use)` | 首次使用 SD 卡，正在创建 CRC |
| `[SET] CRC mismatch! flash data corrupted` | 设置数据 CRC 校验失败，恢复默认 |

## 12. 掉电保持说明

系统有**两套独立的存储系统**：

### 12.1 系统设置（Flash）

| 存储内容 | 位置 | 掉电保持 |
|----------|------|----------|
| 光标灵敏度/大小 | Flash Sector 11 (0x080E0000) | 是（带 CRC 校验） |
| 亮度/音量/熄屏时间 | 同上 | 是 |
| 时间（RTC） | RTC 寄存器（需 VBAT 电池） | 需纽扣电池 |

### 12.2 文件系统（SD 卡）

| 存储内容 | 位置 | 掉电保持 |
|----------|------|----------|
| 文件表（16 个条目） | SD 卡 Block 0（带 CRC，Block 17） | 是 |
| 文件数据 | SD 卡 Block 1~16 | 是 |
| 绘图数据 | SD 卡 Block 17~56 | 是 |

### CRC 保护机制

- **设置 CRC**：每次保存设置时计算 CRC32 写入 Flash。加载时校验，不匹配则恢复默认值。
- **文件表 CRC**：每次写文件表后计算 CRC32 写入 Block 17。加载时校验，不匹配则清理异常条目。
- 作用：防止掉电时写入不完整导致使用损坏的数据。

串口日志会提示 CRC 状态：
- 正常：无日志（静默通过）
- 不匹配：`[SET] CRC mismatch!` 或 `[FS] !!! table CRC mismatch!`

## 13. 常见问题

### Q1：开机后屏幕一直白屏？

**可能原因**：
- LSE 晶振启动慢，导致 RTC 初始化阻塞（已修复，移到任务中初始化）
- SD 卡未插入导致初始化卡住（已修复，异步初始化）

**解决**：等待 5 秒以上，如果仍然白屏，检查串口日志看卡在哪一步。

### Q2：桌面显示 ERR:RTC？

**原因**：首次上电 RTC 时间未设置，或 VBAT 未接纽扣电池。

**解决**：打开 SETTIME 应用设置一次时间即可清除。如果不接 VBAT 电池，每次断电后时间会归零。

### Q3：文件管理显示 [NO SD!]？

**原因**：SD 卡未插入或损坏。

**解决**：插入 FAT32 格式的 SD 卡。文件系统使用裸块读写，不需要预先分区或格式化文件。

### Q4：系统运行中突然重启？

**可能原因**：
- 看门狗超时（某任务卡死超过 5 秒，IWDG 12.5 秒后复位）
- 栈溢出（触发栈溢出钩子）

**诊断**：查看串口日志是否有 `[WDT] !!! task X hang detected` 或 `!!! STACK OVERFLOW !!!`。

### Q5：密码忘了？

**默认密码**：`1234`。密码硬编码在 `User/app/login.c` 第 59 行：
```c
static const char correct_pin[PIN_LEN] = {'1','2','3','4'};
```

### Q6：任务栏最多几个应用？

最多 4 个（`MAX_MINIMIZED = 4`）。任务栏满了后再最小化会失败（应用留在前台）。

### Q7：音乐最小化后还在响？

是的，这是设计如此。音乐应用最小化后音乐继续后台播放。要停止音乐有两种方式：
1. 点击任务栏音乐图标切回去，按 OK 长按停止
2. 点击任务栏音乐图标切回去，按 BACK 退出（自动停止）

### Q8：绘图退出后还能找回吗？

可以。退出时选"YES"保存后，绘图数据存在 SD 卡 Block 17~56。下次打开 DRAW 应用会自动加载并重放之前的绘图。也可以在 FILE 应用中看到 `DRAW.BIN` 文件。

### Q9：光标移动太快/太慢？

在 CONFIG 应用中调整 `Cursor Speed`（范围 1~20，数值越大移动越快）。

### Q10：屏幕太亮/太暗？

在 CONFIG 应用中调整 `Brightness`（范围 0~100%）。**注意**：当前硬件背光只支持开/关，亮度值实际不生效，需要 PWM 改造才能支持。

## 14. 硬件排障：PAM8403 功放无声问题

### 14.1 背景说明

本系统的音频链路为：

```
STM32 PA4 (DAC1_CH1) → 耦合电容 → PAM8403 功放 → 扬声器
```

- **DAC 输出**：PA4 输出方波，中心电压约 1.65V（DAC 值 2048/4095），由 TIM6 中断翻转电平产生音符
- **PAM8403**：3W 立体声 D 类功放，BTL 差分输出，需 5V 供电
- **扬声器**：接功放的 +OUT 和 −OUT 差分输出，**禁止**单端接 GND

如果代码确认正常（MONITOR 应用能看到 `ISR:xxx` 在增长，串口有 `[DAC] DAC_Start` 日志），但扬声器无声，请按以下清单逐项检查。

### 14.2 接线检查清单

| 检查项 | 正确状态 | 错误案例 | 后果 |
|--------|----------|----------|------|
| PAM8403 供电 VDD | 接 5V（USB 5V 或独立电源） | 接 3.3V / 接 >6V | 电压不足推不动喇叭，或芯片烧毁 |
| 共地 | STM32 GND 与 PAM8403 GND 相连 | 两地未接 | 信号无参考地，输入浮空，无声或杂音 |
| 音频输入 | PA4 → 1µF 耦合电容 → PAM8403 L-IN（或 R-IN） | PA4 直接连 PAM8403 输入（无电容） | DAC 输出的 1.65V 直流偏置进入功放，可能饱和失真或损坏 |
| 扬声器接法 | 接 +OUT_L 和 −OUT_L（差分两端） | 一端接 GND、一端接 OUT | BTL 单端输出无电压差，无声 |
| MUTE / SHDN 引脚 | 悬空或接 VDD（高电平=正常工作） | 接 GND（低电平=静音/关断） | 芯片处于静音或关断状态，完全无声 |
| 输入通道选择 | 信号接 L-IN 用 L 输出，或接 R-IN 用 R 输出 | 信号接 L-IN 但喇叭接 R 输出 | 接错通道，喇叭无声 |

### 14.3 供电检查

PAM8403 要求 **2.5V~5.5V** 供电，推荐 5V：

1. **用万用表测量 PAM8403 VDD 与 GND 之间的电压**：
   - 正常：4.8V~5.2V（USB 供电时）
   - 异常 <4V：供电不足，检查电源线压降、USB 线材
   - 异常 >5.5V：电压过高，可能已损坏芯片

2. **供电电流**：播放时应有几十~上百 mA，如果接近 0mA 说明芯片未工作（可能 MUTE 关断或损坏）

3. **不要从 STM32 3.3V 取电**：3.3V 虽在范围内但余量不足，输出功率极小，喇叭可能几乎无声

### 14.4 信号链路检查

#### 步骤 1：确认 DAC 有输出

进入 MUSIC 应用播放音乐，打开 MONITOR 应用查看 `ISR:xxx`：
- `ISR` 数值在快速增长 → TIM6 中断正常，DAC 在翻转
- `ISR` 为 0 → DAC 未启动，检查串口是否有 `[DAC] DAC_Start: TIM6 interrupt started`

#### 步骤 2：测量 PA4 电压

用万用表测 PA4 对 GND 的直流电压：
- **静音时**：约 1.65V（DAC 输出中点 2048/4095 × 3.3V）
- **播放时**：电压在 0.3V~3.0V 之间抖动（方波的平均值仍接近 1.65V，但表针会摆动）

如果 PA4 始终为 0V 或 3.3V，说明 DAC 未正确配置，检查：
- `stm32f4xx_hal_conf.h` 中 `HAL_DAC_MODULE_ENABLED` 是否取消注释
- PA4 是否被其他外设占用（检查 GPIO 复用配置）

#### 步骤 3：检查耦合电容

PA4 与 PAM8403 输入之间**必须**串联一个 1µF 左右的电容（电解或陶瓷均可）：
- 作用：隔去 DAC 的 1.65V 直流偏置，只让方波交流信号进入功放
- 无电容后果：1.65V 直流进入 PAM8403 输入，功放可能饱和，输出严重失真甚至无声
- 极性：电解电容正极接 PA4（直流高电位侧），负极接 PAM8403 输入

#### 步骤 4：检查扬声器

- **阻抗**：PAM8403 推荐 4Ω 或 8Ω 喇叭，不要用 32Ω 以上耳机（推不动）
- **接法**：必须接 +OUT 和 −OUT 两个端子（BTL 差分），**不能**把任一端接 GND
- **断线**：用万用表电阻档测喇叭两端，应有 4~8Ω 直流电阻；无穷大说明断线

### 14.5 MUTE/SHDN 引脚检查

PAM8403 模块通常有 MUTE 或 SHDN 引脚：
- **悬空**：模块内部上拉，默认正常工作
- **接 VDD（5V）**：强制正常工作
- **接 GND**：静音或关断，**完全无声**

如果你的模块有跳线或排针选择 MUTE 状态，确保设置为 HIGH 或悬空。

### 14.6 快速诊断流程

```
扬声器无声
    │
    ├── MONITOR 中 ISR 在增长吗？
    │       ├── 否 → DAC 软件问题（检查 HAL_DAC_MODULE_ENABLED、PA4 配置）
    │       └── 是 → 继续往下查
    │
    ├── 万用表测 PA4 直流电压 ≈ 1.65V？
    │       ├── 否 → DAC 硬件问题（检查 PA4 引脚、DAC 初始化日志）
    │       └── 是 → 信号输出正常，问题在功放
    │
    ├── PAM8403 VDD = 5V？（万用表测）
    │       ├── 否 → 供电问题（换 5V 电源）
    │       └── 是 → 继续往下查
    │
    ├── STM32 GND 与 PAM8403 GND 相连？（万用表蜂鸣档）
    │       ├── 否 → 补接地线
    │       └── 是 → 继续往下查
    │
    ├── PA4 与 PAM8403 输入之间有耦合电容？
    │       ├── 否 → 串接 1µF 电容
    │       └── 是 → 继续往下查
    │
    ├── 扬声器接 +OUT 和 −OUT（差分）？
    │       ├── 否 → 改为差分接法
    │       └── 是 → 继续往下查
    │
    ├── MUTE/SHDN 引脚为高电平或悬空？
    │       ├── 否 → 拉高或悬空
    │       └── 是 → 继续往下查
    │
    └── 换一个喇叭 / 换一个 PAM8403 模块测试
```

### 14.7 常见错误案例

**案例 1：接了 3.3V 供电**
- 现象：喇叭几乎无声，贴近才能听到微弱声音
- 原因：3.3V 供电下 PAM8403 输出功率不足 0.5W
- 解决：改接 5V

**案例 2：忘记接共地**
- 现象：完全无声，或伴随很大杂音
- 原因：信号没有回流路径，PA4 的方波无法被功放正确识别
- 解决：用杜邦线把 STM32 GND 连到 PAM8403 GND

**案例 3：扬声器单端接 GND**
- 现象：完全无声
- 原因：PAM8403 是 BTL 输出，+OUT 和 −OUT 都不接地，单端接法无电压差
- 解决：把扬声器两端分别接 +OUT_L 和 −OUT_L

**案例 4：无耦合电容**
- 现象：有声音但严重失真，喇叭"破音"
- 原因：DAC 的 1.65V 直流偏置直接进入功放，导致工作点偏移饱和
- 解决：PA4 与功放输入之间串接 1µF 电容

**案例 5：MUTE 引脚被拉低**
- 现象：完全无声，但 PA4 有信号、供电正常、接线正确
- 原因：模块的 MUTE 引脚被跳线或接线拉到 GND
- 解决：检查 MUTE/SHDN 排针，设为悬空或接 VDD
